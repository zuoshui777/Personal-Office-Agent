## 1. 进入项目目录

打开终端，执行：

```bash
cd ~/桌面/personal-office-agent
```

> 这一步之后所有命令都在这个目录下执行，除非特别说明。

---

## 2. 创建 Python 虚拟环境

Python 项目需要隔离依赖，不和电脑上其他项目打架。

```bash
python3 -m venv venv
```

执行完会多出一个 `venv/` 文件夹，里面装了一个独立的 Python 环境。

激活它：

```bash
source venv/bin/activate
```

看到终端前面多了 `(venv)` 字样，说明激活成功。

> **将来想退出**：终端里输入 `deactivate` 就行。

---

## 3. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

这条命令会把项目需要的所有 Python 包一口气装进刚才创建的虚拟环境里。

> 装完后可以检查一下：`pip list` 会显示已安装的包列表。

---

## 4. 安装前端依赖

前端是 React + TypeScript 写的，需要 Node.js 的包管理器来装依赖。

```bash
cd frontend
npm install
cd ..
```

> `npm install` 可能会花十几秒到一分钟，取决于网速。

---

## 5. 复制环境变量文件

项目需要知道数据库的地址、密码这些信息，这些信息存在 `.env` 文件里。

项目里有一个模板文件叫 `.env.example`，把它复制一份改名为 `.env`：

```bash
cp .env.example .env
```

然后打开 `.env` 文件，找到这一行：

```
DEEPSEEK_API_KEY=
```

在等号后面填上你的 DeepSeek API Key。如果暂时没有，也可以先空着，只是 AI 问答功能暂时用不了。

> 其他配置项（数据库密码之类的）保持默认就行，因为我们用 Docker 启动的数据库用的就是默认值。

---

## 6. 启动数据库容器

项目需要三个数据库同时运行：PostgreSQL（存用户和文件信息）、Redis（缓存）、Qdrant（向量库）。

最简单的方式是用 Docker 一键启动这三个服务。

```bash
cd docker
docker compose up -d
cd ..
```

> **解释**：`docker compose up -d` 的意思是"根据 docker-compose.yml 的配置，在后台启动所有服务"。
>
> 第一次执行时会自动下载三个数据库的镜像（几百 MB），后面再启动就很快了。
>
> 检查是否启动成功：`docker ps` 应该能看到三个正在运行的容器（postgres、redis、qdrant）。

---

## 7. 初始化数据库表

数据库跑起来了，但是里面还没有表结构。运行初始化脚本创建所有表：

```bash
python scripts/init_db.py
```

> 这条命令会连接 PostgreSQL，执行建表语句。执行后没有报错就说明初始化成功。

---

## 8. 启动后端服务

后端是用 FastAPI 写的 Web 服务，跑在 8000 端口。

```bash
uvicorn backend.app.main:app --reload
```

> **解释**：
> - `backend.app.main:app` 告诉 uvicorn 去找 `backend/app/main.py` 文件里名叫 `app` 的那个 FastAPI 对象。
> - `--reload` 意思是代码改了自动重启，开发时很方便。
>
> 看到 `Uvicorn running on http://127.0.0.1:8000` 说明启动成功。
>
> 启动后这个终端会被占用，要输入新命令的话需要 **新开一个终端窗口**。

---

## 9. 启动前端页面

新开一个终端，进入项目目录：

```bash
cd ~/桌面/personal-office-agent
source venv/bin/activate
cd frontend
npm run dev
```

> 看到 `http://localhost:5173` 说明启动成功。
>
> Vite 自带热更新，改了前端代码页面会自动刷新。

---

## 10. 打开浏览器

在浏览器地址栏输入：

```
http://localhost:5173
```

就能看到 Personal Office Agent 的界面了。

> 这时候前后端全部跑起来，可以：
> - 上传 PDF/Word 文件到知识库
> - 在聊天框问关于文件的问题
> - 查看任务执行状态

---

## 11. 关闭项目

不用的时候按顺序关掉：

```bash
# 1. 停前端 — 在跑前端的终端里按 Ctrl + C

# 2. 停后端 — 在跑后端的终端里按 Ctrl + C

# 3. 停数据库容器
cd ~/桌面/PC_AI/personal-office-agent/docker
docker compose down

# 4. 退出虚拟环境（可选）
deactivate
```

> `docker compose down` 会停掉三个数据库容器，但不会删除数据。
> 如果要彻底删除数据库数据，用 `docker compose down -v`（数据会丢失，一般不用）。
